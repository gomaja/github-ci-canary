# Security Policy

## Reporting A Vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub private
[vulnerability reporting](https://github.com/gomaja/github-ci-canary/security/advisories/new)
and include the affected commit, impact, reproduction steps, and any known
mitigation.

This repository is a release canary rather than a distributed product. Its
default branch continuously pins a reviewed `gomaja/github-ci` commit, and
security fixes are applied to that active canary configuration.
